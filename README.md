# Ajuste de Cor em Imagem 🎨

Este é um projeto simples em HTML, CSS e JavaScript para manipulação de cores em imagens. Ele permite que você carregue uma imagem, aplique filtros e ajustes de cor diretamente no navegador.

## Funcionalidades

- Carregue sua própria imagem para edição.
- Ajuste os canais de cor (R, G, B, A) usando controles deslizantes.
- Aplique filtros bitwise (AND e XOR) para manipulação avançada de cores.
- Visualize as alterações em tempo real.

## Como Executar Localmente

1. Clone este repositório:
   ```bash
   git clone https://github.com/dsilvaphy/Ajuste-de-Cor-Imagem-JavaScript.git

2. Navege até o diretório
   ```bash
   cd Ajuste-de-Cor-Imagem-JavaScript

3. Abra o arquivo index.html no seu navegador.

## Estrutura do Projeto
